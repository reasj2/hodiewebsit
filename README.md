# Hodie — website

Minimal static site hosting the legal and safety documents for the [Hodie](https://github.com/reasj2/hodiewebsit) iOS dating app, operated by SIA "Miglai" (Riga, Latvia).

## Pages

- `index.html` — homepage
- `privacy.html` — Privacy Policy
- `terms.html` — Terms of Service
- `community-guidelines.html` — Community Guidelines & Safety
- `support.html` — Contact & support

## Hosting

Plain HTML + CSS, no build step. Deploy via GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / `/ (root)`**.
